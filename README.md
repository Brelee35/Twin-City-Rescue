Twin Cities Animal Rescue
About the Project

Twin Cities Animal Rescue is a nonprofit animal rescue website created to provide information about animal adoption, fostering, volunteering, and ways the community can support the organization.

The purpose of this website is to increase awareness of Twin Cities Animal Rescue and make it easy for visitors to learn how they can help animals in need.

Website Pages

The website includes four main pages:

Home – Introduces Twin Cities Animal Rescue, its mission, and ways visitors can help.
Services – Provides information about the adoption process, foster program, and volunteer opportunities.
About – Describes the organization, its story, values, and community partnerships.
Contact – Provides information for people interested in volunteering or fostering.

Design

The website uses a consistent color scheme, readable typography, clear navigation, and responsive design to provide an accessible experience on different screen sizes.

Purpose

The goal of the website is to connect potential adopters, foster families, volunteers, donors, and community members with Twin Cities Animal Rescue.
